PosyCHILD ini digunakan untuk menghitung berat badan dan tinggi bayi/balita untuk melihat balita-balita yang kekurangan gizi. Mudah-mudahan para stakeholder yang memiliki kelebihan sumber daya dapat menolong bayi-bayi, balita-balita, anak-anak yang kekurangan gizi agar gizinya cukup menggunakan aplikasi ini.
![Alt text](https://daeyath.wordpress.com/wp-content/uploads/2026/11/posychild-beta.png)

Database yang digunakan berbentuk XML karena keterbatasan peralatan pengembangan. Alat yang digunakan adalah Turbo Delphi Explorer yang mana dbExpress masih terbatas mengakses database yang saya miliki.
